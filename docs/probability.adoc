Determine rate of spread from probability of spread threshold.

[cols="1,2"]
|===
|Parameters |threshold	(Probability of spread threshold)
|Returns |Rate of spread at given threshold (m/min)
|===

Probability of spread is converted into the ROS that would give it, and then when checked the fire burns if ROS > ROS_threshold

`ROS = 25.0 / 4.0 * log(-(exp(41.0 / 25.0) * threshold) / (threshold - 1));`

Should be the inverse of: 

`P = 1 / (1 + exp(1.64 - 0.16 * ros));``

Where P is the threshold above.
