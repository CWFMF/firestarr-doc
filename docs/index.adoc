= FireSTARR Documentation
:experimental:

== Overview

FireSTARR is designed to support wildland fire response decision-making and is the fire growth algorithm originally included in the FireGUARD suite of programs.

It focuses on the generation of burn probabilities from replicated simulation of fire growth, smouldering, and natural extinction under weather and stochastic fire behaviour scenarios.

This documentation is intended to assist users in understanding the FireSTARR program, its inputs and outputs, and how to run it.

For additional technical details see:

https://cwfmf.github.io/FireSTARR/[FireSTARR Technical Documentation]
